# Android 1.0.73 / build 74 and website feedback

This release restores the optional feedback comment in mobile and website staff chat. **Was our staff helpful?** has equal Like / Dislike choices, a Comment field and balanced Continue conversation / Submit feedback actions. Selecting a rating no longer submits immediately. A rating is required; the optional comment is limited to 1,000 characters and trimmed. A successful submission ends the current cycle using the existing endpoint and returns to the unchanged chatbot main menu. Failure preserves feedback for retry; busy controls and the existing mutation guard prevent duplicate requests and stale-poll reopening. Continue conversation does not submit feedback. Website labels remain localized in Tagalog.

Current chatbot staff guidance no longer refers to the former provider. Compatibility code, saved conversations and historical privacy disclosures are not removed. Mobile saved history, the Back/End decision and website minimize/reopen versus refresh/exit behavior remain unchanged. No backend, desktop, database, Firebase, SDK or signing-key changes are included. Unrelated local work is excluded.
