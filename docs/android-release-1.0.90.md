# Android 1.0.90 / build 91

This APK updates the Medical Records screen with a back chevron on the visit
header and hides workspace tabs while a visit is open. The folder illustration
appears after a confirmed empty response. Existing records remain visible
during refresh.

The APK is 100,285,585 bytes with SHA-256
`5d18cdd9c0ca51fb7c1d97897335ca5928bdb70d14a657f189381aa9b9dfb4fa`.
The application ID, build number, signing certificate, bundled source,
eight native modules and both PDF templates were verified.

TypeScript, 45 focused tests and 70 offline Medical Records layouts passed.
Five failures involving retired appointment and booking navigation reproduced
against the prior release source. The mobile repository's matching release note
describes the scope of those checks.

Install this testing-signed APK over a compatible installed version. Result
attachments still depend on the clinic backend's private result-file storage.
